# 读得深 · 三道闸门：初一分诊与训练 Demo

**在线试玩：** https://pumo0926-cpu.github.io/dudeshen-diagnose-demo/

把《初中生阅读问题诊断与可训练提升方案》做成可以真的走一遍的东西：
**20 分钟分诊 → 三道闸门画像 → 一份当天就能练的 15 分钟训练块。**

## 它演示了什么

| | 内容 |
|---|---|
| **三道闸门** | 输入闸（认字·词义·默读速度）→ 加工闸（推断·结构·监控）→ 输出闸（审题·要点·证据·配速）。三者串联，任一堵住，卷面低分长得一样 |
| **三个分离器** | ① 双跑法（同题限时做一遍、不限时重做一遍，B−A 分开「不会」与「来不及」）② 60 秒复述（分开「没读懂」与「写不出」）③ 逐题自信度自评（算校准度，抓「有把握却答错」） |
| **六种画像** | 慢读型／跳读型／散点型／搬运型／失校准型／基础薄弱型（＋暂未偏科）。判定规则、你的实测值、命中的那一条，全部摊开给你看 |
| **17 个微技能** | 每一个都带「做到什么算过关」；全员必练六项，其余按画像启用；三篇不同文本连续达标才算过关 |
| **15 分钟训练块** | 猜·读·问·辨·写五步不变，只在每步挂靶点：P7 标一处没懂 → O1 题干拆解 → O2 分值换要点数 → O4 证据句挂钩 → P4 结构切块 → P5 主旨压缩 → 一句话输出 |

## 几条刻意的设计

- **分诊过程不给对错**——给了，B 卷重做就白做了。所有反馈在报告里一次说清。
- **画像不给孩子看**，也不进家长周报的标题位。报告里并排展示了同一结论的三种写法：不能这么写／给家长（动作语言）／给孩子（只剩一句）。
- **「写」不可跳过**，但门槛压到一句话 15 字。效应量最大的零件不能是选项。
- **多条规则同时触发是常态**（闸门串联），判定取最靠前的一条——先治底层病因。

## 内容与数据

- 分诊选文《我的第一次值日》、训练选文《为什么童年的事，记得格外牢》均取自首月内容库（原创选文，版权自持）。
- 词义速判取七上课内文言实词（《咏雪》《陈太丘与友期行》）与选文词。
- 同龄人分布为**模拟数据**。你的作答只存在浏览器内存里，刷新即清空，**不上传任何服务器**。
- 为便于试玩做了压缩：首测 20 分钟 → 约 8 分钟，词义速判 20 题 → 10 题；判定规则与阈值与方案一致。

## 构建

零依赖静态页，只要 Python 3：

```bash
python3 tools/build.py     # 读 ../content/month01.json ＋ 手写探针，生成 index.html
```

`tools/build.py` 里 `PROBE`／`EVID`／`RETELL`／`VOCAB`／`PROFILES`／`SKILLS` 是分诊与训练的全部规则，
改判定阈值只改这一处。

> 内部工作稿，公开仅为便于评审。文中的阈值、配比、时长均为**待验证建议，不是承诺**。
