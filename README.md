# 读得深 · 三道闸门：初一分诊与训练 Demo

**在线试玩：** https://pumo0926-cpu.github.io/dudeshen-diagnose-demo/

把《初中生阅读问题诊断与可训练提升方案》做成可以真的走一遍的东西：
**读一篇 → 知道自己哪一步最费劲 → 一份当天就能练的 15 分钟。**

## 两层视角，同一次作答

打开就是**孩子视角**（默认）。右上角「给大人看」切到产品层，同一份作答换一种呈现。

| | 孩子看到的 | 大人看到的 |
|---|---|---|
| 开头 | 「先读一篇，再说说你怎么想。不打分，也不排名。」 | 三道闸门模型、分诊五环节与用途 |
| 读的时候 | 不显示秒数（跳字的倒计时只会让人越读越慌），改成一条不出数字的进度；有「读不下去了」的出口 | 计时器、字数、6 分钟上限 |
| 题面 | 只有题，没有 L1/L2/探针/校准这些词 | 层级与考点标注 |
| 读完 | 「今天这一篇你做到了 4 件」＋ 具体哪几件 ＋ 今天练哪一件 ＋ **你自己觉得最费劲的是哪一步** | **家长版**：一句人话的结论 ＋「八件事逐条说」＋ 本月只主攻一件 ＋ 四周后怎么验证 ＋ 三条红线；判定规则、闸门分数、类型名全部收进折叠的「判定细节」 |
| 训练块 | 「标一处你没看懂的地方」「一道题在问什么，其实就三件事」「4 分写几点」 | 同样的练习，标题下多一行「靶点：O1 · O2 · O4」 |
| 收尾 | 「今天读完了」＋ 七件具体做到的事 ＋「断一天也不清零」 | 微技能达标与 1/3 进度、回测规则 |

**画像名、闸门分数、微技能编号，孩子一个都看不到**——这是方案 09 §8 定的红线：标签会自我实现，初中生对「我是差的那一类」极其敏感。采集的数据两层完全相同，只是说法不同。

## 它演示了什么

| | 内容 |
|---|---|
| **三道闸门** | 输入闸（认字·词义·默读速度）→ 加工闸（推断·结构·监控）→ 输出闸（审题·要点·证据·配速）。三者串联，任一堵住，卷面低分长得一样 |
| **三个分离器** | ① 双跑法（同题限时做一遍、不限时重做一遍，B−A 分开「不会」与「来不及」）② 60 秒复述（分开「没读懂」与「写不出」）③ 逐题自信度自评（算校准度，抓「有把握却答错」） |
| **六种画像** | 慢读型／跳读型／散点型／搬运型／失校准型／基础薄弱型（＋暂未偏科）。**只在大人那一层出现**；判定规则、你的实测值、命中的那一条，全部摊开 |
| **17 个微技能** | 每一个都带「做到什么算过关」；全员必练六项，其余按画像启用；三篇不同文本连续达标才算过关 |
| **15 分钟训练块** | 猜·读·问·辨·写五步不变，只在每步挂靶点：P7 标一处没懂 → O1 题干拆解 → O2 分值换要点数 → O4 证据句挂钩 → P4 结构切块 → P5 主旨压缩 → 一句话输出 |

## 「题干拆解」是怎么讲清楚的

第一版这一关写的是「点出三样：指令动词、范围限定、数量限定」——术语堆在一起，孩子（和大人）都不知道要干什么。现在改成**一件一件填**：

```
结合第④⑤段，说说这样安排有什么好处。（4 分，答两点）

没做过？先看一个例子 ›          ← 展开是另一道题的标准拆法

1. 要你干什么？  一个动词：说说 / 分析 / 概括…   [ 点下面的词 ]   ← 当前
2. 去哪儿找？    哪几段，还是全文                [      ]
3. 要写几点？    题目直接说了几点，或者从分数推  [      ]

[结合] [第④⑤段] [说说] [这样安排] [有什么好处] [4 分] [答两点]
```

- 一次只问一件，当前那一格高亮，填对自动跳下一格；
- 点错分两种回法：**点了后面那一件** →「『答两点』是『要写几点』那一件，等会儿才轮到它」；**点了无关词** →「『4 分』是分数，它能帮你推出写几点，但它本身不是『要写几点』那句话」；
- 内部编号（O1/O2/O4）只在大人视角作标题下的一行小字，孩子那层一个字都不出现。

## 导航与进度

- **每一屏都能「‹ 上一步」**，而且退回去<b>状态还在</b>：答过的题保留选项与自评（可以改）、标过的段落还标着、四关的进度和填好的空都在。分诊的答题环节、训练块五步、微技能面板与疗程页全部可回退；报告页给的是「从头再来」。
- **步骤条带名字**：分诊是「读一篇 / 答八题 / 说一遍 / 再来一次 / 十个词」，训练块是「猜 / 读 / 问 / 辨 / 写」，当前那一步高亮、已完成的变浅——不再是五根没名字的横线。
- **第 3 步的四小关做成带状态的卡**：每关标着「✓ 完成 / 现在这关 / 还没开」，过一关自动滚到下一关，并在反馈里明说「这一关过了，下面是第 ② 关」＋ 一个「去第 ② 关 ›」按钮。（原先重绘会把人弹回页首，下面新出现的关卡根本看不见。）

## 大人那一层＝家长那一页

早先大人视角直接摊开了六条判定规则和 `L1 3/3`、`B−A 0%`、`10/10` 这类写法——家长看不懂。现在这一页按家长重做：

- **结论是一句人话**：「自我感觉和实际有差距」，不是「失校准型」；类型名连同闸门分数、判定阈值全部收进最后的折叠区。
- **八件事逐条说**，每条三段式：我们看了什么 → 他的结果 → **这说明什么**。例如「给时间、允许翻回原文再做一遍：2 道改对（共 3 道）→ 差别明显：不少题是『来不及／没细看』，不是真不会——先练配速和审题最划算。」
- **本月只主攻一件事**，并写明孩子那边看到的原话是哪一句。
- **四周后怎么验证**：换一篇没读过的文章再测同样八件事；并明说「只是做得多了、打卡天数长了」不算数。
- **三条红线**摆在页面上：不预测分数、不排名、不给孩子贴类型。

## 写完那句话之后

第 5 步要求孩子写一句（不可跳过、15 字门槛），原先写完直接跳结算页，**对他写的内容一个字都不提**——这是整条动线上最贵的一处损耗：要求是真的，重视是假的。

现在写完先进**回应屏**：把那句话原样摆出来，给三条按字面可算的回应（写的是不是自己的事／有没有说清是「牢」还是「准」／有没有具体细节），再给两条同龄人样例做对照，最后如实说明「Demo 不联网、不接 AI，这三条是按字面算的；真实产品里这一步由 AI 读内容」。**诚实地给一个弱反馈，好过假装一个强反馈。** 那句话随后收进结算页。

完整的动线审计（9 个阻碍点与损耗点、三条通用规则、明确不改的三件）见文档
[12 答题动线审计](https://pumo0926-cpu.github.io/dudeshen-docs/doc-12.html)。

## 不把人卡死

凡是「条件不满足就没有下一步按钮」的地方，都必须说清**还差什么**，并且门槛分两层：

| | 能不能往下走（宽松） | 算不算达标（严格，进微技能记录） |
|---|---|---|
| 第 4 步 · 切块起名＋主旨 | 三块都起了名字 ＋ 主旨 ≥8 字 | 标题每块 2–6 字 ＋ 主旨 8–30 字 ＋ 不是套话 ＋ 带上本篇关键词 |
| 第 5 步 · 写一句 | ≥15 字 | 同左 |

没达标也能走，反馈会说「够了，可以往下走。要更好的话：……」；真的没填完则挡住，但明写「还差：还有 1 块没起名字」。第 4 步另配一个「不知道怎么写？看看写法」——给骨架和别篇的范例，不给本篇答案。

## 几条刻意的设计

- **分诊过程不给对错**——给了，B 卷重做就白做了。所有反馈在报告里一次说清。
- **画像不给孩子看**，也不进家长周报的标题位。大人那一层并排展示同一结论的三种写法：不能这么写／给家长（动作语言）／给孩子（只剩一句）。
- **孩子那一层不出现任何总分**：读完给的是「做到 4 件」这种行为计数，不是能力值，也不跟别人比。
- **最后让孩子自己认领一句**「刚才最费劲的是哪一步」——判定可以由系统算，但要不要认，得他自己说了算；选完会告诉他跟系统看到的一不一样。
- **「写」不可跳过**，但门槛压到一句话 15 字。效应量最大的零件不能是选项。
- **多条规则同时触发是常态**（闸门串联），判定取最靠前的一条——先治底层病因。

## 内容与数据

- 分诊选文《我的第一次值日》、训练选文《为什么童年的事，记得格外牢》均取自首月内容库（原创选文，版权自持）。
- 词义速判取七上课内文言实词（《咏雪》《陈太丘与友期行》）与选文词。
- 同龄人分布为**模拟数据**。你的作答只存在浏览器内存里，刷新即清空，**不上传任何服务器**。
- 为便于试玩做了压缩：首测 20 分钟 → 约 8 分钟，词义速判 20 题 → 10 题；判定规则与阈值与方案一致。
